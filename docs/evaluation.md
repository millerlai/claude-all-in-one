# 評估依據

整理日期：2026-11-02。本頁保留仍有比較價值的歷史量測，不是本次重新執行的結果。當時的模型、工具版本、價格與流程均不保證適用現在；未重新執行付費模型評估。

術語：行為評估（eval）以固定輸入檢查模型輸出；評分器（grader）判斷某一條件；基準案例（benchmark case）是已標註缺陷的變更；精確率（precision）是回報中命中的比例；召回率（recall）是已知缺陷被找出的比例；綜合分數（F1）結合前兩者；耗用單位（token）記錄模型使用量。
