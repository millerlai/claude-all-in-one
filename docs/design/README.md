# 設計文件

目前實作請先讀 [文件總覽](../README.md)。這裡只保留仍有獨立價值的未實作設計，不再保存已完成功能的整套日期式設計、簽核與施工備註。

## 第二版架構提案

[第二版架構](architecture-v2.md) 保存原架構研究收斂後的需求、資料契約、能力門檻、重建順序與驗收計畫。重複研究與外部審查的採納／拒絕理由已在該文件第 17 節整合，原稿由版本歷史追溯。

**狀態：提案尚未取得整體實作核准，也未交付。** 它規劃另建版本庫、使用新名稱、建立新的狀態與受保護控制入口，不能當作本專案已有的能力或已執行的搬遷。部分原則已在目前版本實現，例如主工作階段直接執行設計、驗證與發布準備；這不代表整套第二版已落地。

保留原獨有範圍決定，包括未來指令去留、跨平台續行、每個工作目錄的軌道綁定與用量驗收門檻。這些只適用提案，不改變目前已出貨的指令與相容性。

## 後續新增設計

新的設計仍由 [stage-design.md](../../plugins/cai/skills/track/references/stage-design.md) 決定格式，必要時寫成單份 `<date>-<topic>-design.md`；本次整理不修改產品產生設計的路徑與契約。

功能完成後，將仍有維護價值的內容併入 [現行主題文件](../README.md)，更新程式引用，再移除已被取代的文件。原始核准、嘗試與執行證據留在軌道資料中，不複製成第二套現行規格。
